# 自主避障课程 v3：参考一致性、收敛与 BC 放行修正

v2 单静态阶段已训练完成，但 BC/PPO 对准与避障均失败；诊断发现 BC 关闭跟踪先验并失去收敛能力。
v3 代码修正阶段只修改代码并运行推理/回归检查；随后用户授权了首次阶段运行，结果见下文。
已有模型和历史结果保留；旧配置归档在 `configs/staged_avoidance_v2.yaml`，仅用于诊断。
配置：`configs/staged_avoidance.yaml`；入口：`scripts/staged_avoidance.py`。
默认不带操作参数时只检查配置和模型空间，不创建数据/训练目录。

## 1. 难度课程

| 阶段名 | 障碍物数量 | 运动 | 位移幅度上限 | 速度上限 |
|---|---:|---|---:|---:|
| one_static | 1 | 静止 | 不移动 | 0 |
| one_dynamic | 1 | 三轴平滑随机 | 0.05 m | 0.02 m/s |
| three_dynamic | 3 | 三轴平滑随机 | 0.10 m | 0.05 m/s |
| five_dynamic_low | 5 | 三轴平滑随机 | 0.10 m | 0.05 m/s |
| five_dynamic_full | 5 | 三轴平滑随机 | 0.40 m | 0.40 m/s |

使用完整五障碍物锚点场景作为几何来源，按参考轨迹中部选择单障碍物（原索引 2），
三障碍物选原索引 1/2/3，最后使用全部。尺寸保持不一；初始/目标采用完整运动范围的
端点安全检查，但不保证整个运动问题必定可解。小幅运动只表示运动强度低，不保证
几何上更容易。单个静态阶段是新的低难度起点，不是把原五障碍物验证标准放宽。

每阶段独立种子范围：训练从 800000 + 阶段索引×10000 开始，验证从
900000 + 阶段索引×10000 开始。每阶段 64 个训练布局、20 个阶段验证布局。
仍采用 20% 无障碍对准、30% 静态、50% 动态的回合抽样；在静态阶段后两类均冻结为
该阶段的静态布局。对准回合近/远各半。观测仍 77 维，少于五个障碍物时填零。
保留 20 个远/近对准案例；早期阶段另报告 10 个五障碍物完整强度案例作为诊断，
不让它们阻止初级课程推进。最终阶段按五障碍物完整强度验收。

## 2. 离线专家示范与 BC

每阶段预设采集 80 个避障成功回合和 20 个对准成功回合，最多尝试 500 回合。
避障专家在离线仿真中使用 ClassicalController：静态场景用 RRT，动态场景用时间调度。
显式传入原参考的终点关节角，不再通过独立多起点 IK 选择另一条目标分支。
目标无效时记录失败，不偷偷回退到其他 IK 分支。对准示范直接使用与策略相同的参考/终端跟踪器，
不调用独立 IK/RRT，不从上阶段残差网络生成对准标签。
失败、规划耗时和重新规划均记录，失败不冒充成功标签。找不到路径不等于证明无解。
未满足示范配额时拒绝 BC；至少需要 10 个不同场景种子。

关键区别：保存给学习策略的 77 维观测始终包含原来的“未考虑障碍物的参考”，
动作标签来自专家绕行/等待的执行指令。专家避障路径不会替换策略参考输入。
`teacher.npz` 保存 obs、投影后动作标签 actions、投影前 raw_actions、回合 offsets、
种子和任务类别；还单独保存每个成功回合的 `terminal_obs/terminal_actions`。
这些成功后观测是监督锚点，不计入环境步数，也不会在 done 后执行动作。
终端标签来自固定的参考/终端跟踪器。失败尝试保存在 attempts.json。教师未来运动信息只用于离线标签，
执行策略没有这些未来信息，也不调用专家或在线规划器。

BC 只更新避障残差网络和跟踪门控，critic、原跟踪系数、动作标准差保持不变。
按场景种子划分 80/20 检查集，避免同一布局的不同回合同时进入两边；这仍是训练场景
内部检查，不是独立测试成绩。默认 2000 次 Adam 更新、batch 256、学习率 0.001；
对准/避障各占半个 batch，组内按回合均衡采样。两组必须在训练/检查分区中均有样本。
原回合抽样比例 20/30/50 不变；这个 50/50 只针对 BC 小批量。

BC 目标为动作 MSE + 2×终端锚点 MSE + 0.01×门控保留项 + 0.001×残差幅度项。
后两项仅作用于有效的避障修正，允许必要的等待/绕行，不强制门控永远为 1。
按分任务均衡动作 MSE + 2×终端 MSE 选择检查集权重，同时记录各项；它不能替代闭环验收。
BC 更新不计为 PPO 环境步数。v3 强制检查接口版本与配置，不允许直接复用 v2 示范或 BC 权重训练。

## 3. 探索与跟踪门控

无障碍时只使用固定跟踪器；存在障碍物时学习减速/绕行。新动作均值：

`clip((1-c+c*sigmoid(gate(obs))) * prior + c*2*tanh(residual(obs)), -1, 1)`

`c = obstacle_present * clip(max(abs(q-goal_q))/0.20, 0, 1)^2`。
presence 读取五个槽的存在标记，既不看未来运动，也不做碰撞动作拒绝。
prior 在每关节最大目标误差 0.20 rad 内，从原路点跟踪平滑过渡到无偏置的固定目标关节伺服；
这样到目标时不再因过期路点或独立残差输出持续移动。修正随误差二次趋零，原终端伺服为一阶。
这不是全局稳定性或避碰证明，物理执行仍按原碰撞规则判定。

门控和避障网络均读取全部 77 维观测。存在障碍且远离目标时，门控初始 0.5、残差为零；
无障碍时门控实际为 1、残差为零，与网络学到的值无关。固定目标关节角为策略配置常量，未增加观测维度。
原模型的跟踪系数和 critic 权重被继承；PPO 使用新优化器，BC 使用单独的优化器。
新参数冻结规则在保存/重载时保持。

参考游标保持沿原路线单调前进。当偏离当前路点超过 0.08 rad 时，查询前方原参考段的最近投影；
若距离不超过 0.30 rad 且比当前段改善超过 0.02 rad，则恢复到该前方段。
不修改原参考路线，不引入专家路径或在线规划器，也不覆盖动作；info 记录恢复次数。

默认探索标准差从 0.02 提高到 0.10，约为每关节 0.4° 的采样尺度（执行限幅前）。
0.15 可作为另一份配置的对照，不会自动切换。实际步幅仍每关节最多 4°。
原始高斯采样及其概率保留在 PPO 缓冲区，执行层统一做 Box 和关节限位裕度投影。

## 4. 奖励调整

保留物理任务的目标进展、碰撞 -50、越界 -30、成功 +100、动作及时间代价。
位置 <1 cm、姿态 <2° 的安装标准保持不变。
路点进展奖励系数从 2.0 降为 0.25，且始终先对同一路点计算前后进展，再推进游标。
新增障碍物距离项：

`-0.5 * clip(1 - d_min/0.08, 0, 1)**2`

`d_min` 查询整条机械臂所有链接及墙板到障碍物的距离。距离项范围 [-0.5,0]；
超过 8 cm 时为零，无障碍物时为零。墙体不加入该距离项，避免对合法安装的墙面间隙
产生持续惩罚；物理墙体碰撞仍按原任务检查。距离仅用于奖励，不拒绝/替换动作，
也不构成安全保证。info 记录该奖励分量和截断后的最小距离。

## 5. 短预算与阶段验收

每阶段默认追加 10000 个 PPO 环境步，四环境各采样 250 步/轮，batch 100、三 epoch，
学习率 1e-4、clip 0.05、target KL 0.005。仅当前阶段短训练，不自动追加步数或运行下阶段。
PPO 必须显式加载当前阶段的 BC 模型，不能跳过示范直接盲目长训练。

BC 完成后自动运行只推理的闭环检查；也可用 `--validate-bc` 单独重查。BC 放行要求：

- 至少 20 个当前阶段场景，成功率 ≥50%、碰撞率 ≤25%、关节越界为零；
- 远/近对准各至少 10 个案例，成功率各 ≥90%，对准碰撞和关节越界均为零；
- 在固定目标处，分别检查无障碍/有障碍标记两种输入，最大确定性动作 ≤0.005；
- 原模型、示范、配置、模型类型与接口版本一致。

这些是进入短 PPO 试验的最低条件，不替代下述更严格的阶段推进验收。
`--train` 每次重新验证当前权重，不凭旧的 passing JSON 放行。失败结果写入
`bc/closed_loop_gate.json`，在创建 PPO 输出目录、采样进程和调用 learn 之前报错停止。
`bc/closed_loop_episodes.json` 保存各回合；五障碍物诊断仍不参与早期放行。

验证在参数更新后进行，最终保存权重重新加载后验证。三种方法共享场景、运动相位和
未考虑障碍物的参考，报告成功、碰撞、越界、超时及超时位置/姿态误差，另报告对准保留。
阶段 gate 默认要求：

- 至少 20 个阶段案例，成功率 ≥80%，碰撞率 ≤10%，关节越界为零；
- 远/近对准各至少 10 个案例、成功率各 ≥90%；
- 至少两次不同新增步数的更新后检查连续通过，初始化成绩不计；
- 被选中的模型也必须满足验收，且该阶段完整预算确实完成。

通过 gate 的候选在模型选择中优先；否则保留明确的失败结果，不把奖励上涨当成功。
下阶段 BC/PPO 会检查上阶段 assessment、门槛和被选模型的哈希。未通过则阻止推进。
这些是工程验收阈值，重复固定验证不是独立统计证据；最终独立测试仍需另行安排。

## 后续使用命令（本次均未执行昂贵操作）

在工作副本根目录运行：

```bash
# 默认只检查，可随时运行。
python scripts/staged_avoidance.py --stage one_static

# 以下各操作都需显式选择，前一步材料缺失会报错，不自动补做。
python scripts/staged_avoidance.py --stage one_static --prepare
python scripts/staged_avoidance.py --stage one_static --collect-teacher
python scripts/staged_avoidance.py --stage one_static --pretrain
# pretrain 已自动验证；下面可以单独重查，只推理不学习。
python scripts/staged_avoidance.py --stage one_static --validate-bc
python scripts/staged_avoidance.py --stage one_static --train
python scripts/staged_avoidance.py --stage one_static --assess
```

数据：`data/staged_avoidance_v3_seed61/<阶段>/`，其中 teacher/ 存示范。
模型：`models/staged_avoidance_v3_seed61/<阶段>/bc/` 和 ppo/。
权重与示范不覆盖已有文件；配置或物理环境变化需使用新的实验输出目录。
验收后，再手动选择下一阶段，沿用同样的显式工作流。没有“一键连续训练所有阶段”的命令。

## v3 代码验证结果（不是训练结果）

在原有验证场景上，无训练的 v3 初始化完成远/近对准各 10/10。
把旧 BC 权重仅加载到内存中的新结构作消融，对准也恢复为各 10/10；没有保存为 v3 模型。
目标处有障碍标记时的最大动作约 1.71e-6。旧专家轨迹上游标未达 90% 的回合从 78/100 降到 10/100。
单障碍物场景初始化仍为 0/20，旧 BC 权重消融为 2/20，均未达到 BC 放行要求。
这些检查验证了保留对准与参考恢复机制，并不代表新避障策略已经训练成功。

## 首次 v3 阶段运行结果（2026-10-27）

已准备 64 个训练布局和 20 个目标验证布局，生成失败为零。
100 次尝试均成功：20 个对准、80 个避障回合，共 4,794 条状态—动作数据，50 个不同场景种子。
已完成 2,000 次 BC 更新，检查集选模目标为 0.00801880。

BC 的真实闭环验证：单静态障碍物 0/20 成功、20 次碰撞；远/近对准各 10/10，
无碰撞/越界/超时；有/无障碍标记的目标动作约 1.71e-6。
BC 仍未达到避障放行门槛，因此流程正确停止，未创建 PPO 输出目录、未追加 PPO 步数、
未进入下一阶段。这表明对准/收敛退化已修正，但 BC 尚未学会可靠避障。
应先诊断剩余避障失败，而不是绕过放行检查或直接延长 PPO 预算。
