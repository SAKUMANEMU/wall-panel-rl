## 修改

1. 对准标签使用策略自己的固定参考/终端伺服；避障专家明确使用原参考终点关节角，
   避免独立 IK 分支；原参考仍不含专家绕行路径。
2. 参考游标可重新定位到更接近机械臂的前方原路线段，只单调向前，不修改动作或路径。
3. 新策略无障碍时关闭学习残差并保留跟踪；接近固定目标时，残差/门控修正二次衰减，
   基础跟踪平滑过渡到无偏置的终端伺服。旧模型类保持原行为。
4. BC 采样平衡对准/避障，增加成功后观测的终端监督，以及轻度门控/残差保留项。
5. BC 后自动闭环验证，PPO 启动前再次验证当前权重。当前阶段成功率至少 50%、碰撞率
   最多 25%、无关节越界；远/近对准各至少 10 例、成功率至少 90%、无碰撞/越界；目标
   动作最多 0.005。失败报告保留，PPO 输出/进程/learn 尚未创建便停止。
   后续阶段推进仍要求原来的 80% 成功、10% 碰撞上限等条件。

v3 配置/输出和旧实验隔离，v2 示范及 BC 权重不能直接用于新的正式训练。
新默认配置 `configs/staged_avoidance.yaml`；旧配置 `configs/staged_avoidance_v2.yaml` 仅用于重现诊断。
