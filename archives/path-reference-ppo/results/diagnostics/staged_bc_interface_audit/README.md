# 单静态障碍物阶段：BC 策略与动作接口诊断

检查日期：2026-10-27。未训练、未采集新的真实专家示范、未更新或覆盖已有模型。
这些是故障诊断，使用了训练数据及已有验证场景，不是独立测试成绩。

## 结论

没有发现观测与动作标签错位、动作符号/单位/缩放错误，或 BC/PPO 推理接口不一致。
已复现的主要故障是 BC 改变了原跟踪行为，失去闭环收敛能力；PPO 从这个已经退化的
初始化继续训练。训练的动作 MSE 不能代替回合成功率。

## 动作接口核查

- 观测 77 维，动作 7 维，动作含义是归一化关节增量，不是绝对关节角。
- 环境执行 `desired_q = current_q + action * radians(4)`。
- 统一执行层先做 [-1,1] 限幅，再做 0.01 rad 关节裕度投影。
- 对全部 4,829 条示范观测，四种模型的 `tracking_mean`、确定性 `forward`、
  `predict` 完全一致；`forward` 与 `evaluate_actions` 的动作 log probability 一致。
- 保存/重载前后确定性动作差为 0。
- 原模型动作标准差 0.02，新策略/BC/PPO 为 0.10，符合配置。
  本次闭环诊断使用确定性动作，因此失败不由探索采样噪声造成。
- 专家原始动作和存储的执行标签最大差为 0；这批数据没有触发执行投影。
- 按原始初始场景重放所有 100 个成功专家回合：100/100 成功。
  每一步观测与已存观测的最大差为 0，执行投影计算差为 0；
  从 float32 观测反解关节角的最大误差约 2.65e-7 rad。

## 已发现的策略问题

### 1. 原参考与专家标签存在方向冲突，门控被压低

策略输入始终保留未考虑障碍物的原参考，这是设计要求；专家实际执行自己的绕行/
IK/RRT 路线。两者不同本身不等于标签错误，但当前参考游标只能在靠近/通过局部路点时
推进，偏离参考后不能充分恢复进度。

在 100 个成功专家回合的最后一个“动作前”观测上，有 78 个回合的游标未达到原路线的
90%（对准 18/20，避障 60/80）。平均游标进度分别为 54.8% 和 41.1%。
对标签绝对值 >0.05 的关节，按回合平均统计，原跟踪动作与专家标签异号的比例分别
约 47.9%（对准）和 69.7%（避障）。这是方向冲突诊断，不是“专家动作错误率”。

在所有示范观测上，BC 学到的门控 min/mean/max 约为 0.0058/0.0197/0.1200；
几乎关闭原跟踪先验，依赖残差网络直接输出动作。
这个现象支持“参考/标签不协调促使网络放弃先验”的解释，但不是独立因果消融证明。

### 2. 单步拟合误差不小，闭环没有恢复机制

按不同场景种子划分的 BC 检查集 MSE 为 0.0097627，RMSE 为 0.098806。
对应每关节指令增量的 RMSE 约为 0.395°（不是最终姿态误差）。检查集动作绝对误差的
95 分位约 0.1886，即约 0.754° 的关节指令差；少数样本误差更大。
BC 在专家状态上拟合动作，但执行自身动作后会进入不同状态，误差可累积。
示范重放成功而 BC 在相同示范场景闭环失败，说明单步检查集损失不足以验证控制能力。

### 3. 没有保留目标处的收敛行为

把每个对准验证场景直接放在其原参考终点：20/20 初始状态满足原安装成功条件。
这些状态下原跟踪模型最大动作绝对值为 0.000537；BC 为 0.326212，
即单次最大指令关节增量约 1.305°，所有目标动作分量平均绝对值约 0.1021。
当前独立残差头没有在目标误差趋零时自动趋零的结构约束。
这是“到达目标后的动作”诊断，不表示原评估会在已成功回合后继续执行动作。

抽查一个远对准回合，BC 在第 73 步失败，位置误差约 0.260 m，姿态误差约 9.92°，
检测到墙板与墙体穿透；另一个近对准回合在第 40 步失败，位置误差约 0.191 m，
姿态误差约 11.83°，墙板与墙体距离约 7.46e-5 m（按原碰撞间隙规则判碰撞）。
无障碍只表示没有额外盒状障碍物，墙体及机械臂自身碰撞检查仍存在。

### 4. 工作流缺少 BC 后的闭环放行检查

现有 PPO 入口检查了示范完整性、哈希、配置和上阶段验收，却没有在当前阶段 BC 后
验证对准保留能力并阻止退化模型进入 PPO。原工作流因此对已经失去对准能力的模型
执行了既定 10,000 步训练。当前阶段最终验收已正确失败，后续阶段未启动。

## 建议修改顺序（本次没有修改策略或训练流程）

1. 对准示范使用与原参考一致的跟踪行为；避障示范保持原输入参考，但固定/约束目标
   IK 分支并为绕行后的参考游标加入可验证的向前重定位，避免把专家绕行路线泄漏为策略输入。
2. 保留原跟踪器的对准与终端收敛：给门控/残差增加对准保留目标及近目标监督，
   并在策略结构中让修正随合适的任务误差趋零，而非只最小化全数据动作 MSE。
3. BC 后先做小规模闭环验证和同场景专家重放；至少通过对准保留检查后才允许 PPO。
   验收使用真实的成功/碰撞/超时，不用降低 MSE 作为替代。
4. 上述问题修正后再考虑采集偏离专家轨迹后的纠偏示范，例如 DAgger。
   不建议对当前失败模型直接延长 PPO 预算。
