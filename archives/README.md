# Archived local workspaces

These are ordinary files, not Git submodules, so a normal clone includes them.

| Uploaded directory | Original local directory |
|---|---|
| `archives/path-reference-ppo/` | `.worktrees/path-reference-ppo/` |
| `archives/branch-reproductions/` | `branch-reproductions/` |

Nested Git metadata, Python environments and caches are excluded. Code, model
checkpoints, datasets, experiment outcomes and reports are retained. Historical
absolute paths in saved metadata describe the original machine; run current
experiments through the portable commands in `CURRENT_PROJECT.md`.
The reproduced alternative branch is historical material, not the active model.
