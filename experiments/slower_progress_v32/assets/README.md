# Robot assets and attribution

`robot/kuka_iiwa/` is copied unchanged from `pybullet_data` distributed with
PyBullet 3.2.7. The project loads `model.urdf` with its local visual/collision meshes.
Source: https://github.com/bulletphysics/bullet3/tree/master/examples/pybullet/gym/pybullet_data/kuka_iiwa

The URDF retains the full BSD-style two-clause license, copyright 2015 Robert Krug
and Todor Stoyanov, AASS Research Center, Orebro University, Sweden. It identifies
the original xacro source as https://github.com/rtkg/lbr_iiwa . Preserve those
notices when redistributing the model and associated assets.

This is a seven-revolute-joint KUKA LBR iiwa, not a UR5. No standalone verified
UR5 asset was supplied, so the specification's standard-manipulator fallback was
used. The action dimension is seven. Simulator FK/IK and collision geometry are
used directly; kinematics are not approximated by a fabricated model.

The box panel, wall and obstacles are generated by this project's code.
