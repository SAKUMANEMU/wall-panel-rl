# 每回合 RRT/PPO 随机切换：训练前接口验证

已完成代码接入与固定场景评估，未启动正式混合训练。
每个回合独立以50%概率选择RRT或PPO，整回合保持同一控制器。
RRT提供成功示范，单独用于BC损失；PPO缓冲区只保存自己的采样。

| 模式 | 目标场景成功 | 碰撞 | 超时 | RRT/PPO回合数 |
|---|---:|---:|---:|---|
| 纯PPO | 17/20 | 0 | 3 | 0/20 |
| 纯RRT | 20/20 | 0 | 0 | 20/0 |
| 50/50混合 | 18/20 | 0 | 2 | 8/12 |

每组另有远近对准各10例，共20/20成功；均无关节越限和规划失败。
混合组全部40回合中16个RRT、24个PPO。概率50%不等于有限样本强制各半。

这些都是已见验证场景，不是新独立测试。混合成功率包含在线RRT规划的贡献，
不能当成PPO自身的成功率，也不代表重新训练后的提升。
采用的PPO是既有追加10k候选，按教授偏好的碰撞优先规则重新选择；
原18/20模型及其282/300回归结果保留，后者不属于本候选。

测试：128项全量回归，加1项新增8步人工环境集成测试通过；
集成测试验证实际PPO更新与辅助BC更新交替后，每批原始动作概率仍一致。
演示：相同种子1000000，PPO在59步成功，RRT在50步成功。

配置：configs/episode_rrt_ppo.yaml；说明：docs/EPISODE_RRT_PPO.md。
默认训练入口仅检查配置；--train才开始10,000个PPO步及额外RRT回合。
此处没有生成正式混合训练模型或训练曲线。
