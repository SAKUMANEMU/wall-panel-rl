- 增加原采样网格之外的0.005弧度细采样，并覆盖控制器加密后的实际路点。
- 直线路径、捷径和完整候选路线均经过验证；不合格候选继续搜索，预算耗尽返回规划失败。控制器另有最终拒绝防线。
- 全部找到的主评估路径均在执行前验证通过，事后原网格复检也通过。有限采样不构成连续碰撞安全证明。

- 更密检查增加规划墙钟时间；规划期间仿真时钟仍暂停，没有模拟延迟或改变执行器。
